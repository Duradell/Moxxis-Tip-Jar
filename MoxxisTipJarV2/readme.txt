MOXXI'S TIP JAR - WEAPON ENCODING RESEARCH PROJECT

== WHAT THIS IS ==
Utility tool to create weapons through checkpoint discovery

== THE DISCOVERY ==
Through systematic testing, we discovered the game doesn't accept random custom codes. Instead, it transforms inputs to pre-existing "checkpoints" in a hidden validation table. This explains why 99% of random codes fail - they don't route to valid checkpoints.

== HOW TO USE ==
1. Download the packet
2. Install Moxxi
3. Run Moxxi  
4. Enter steam ID
5. Select your .sav
6. Enter weapon @ID
7. select .sav (overwrite)
8. when prompted back out to the title screen
9. then ensure your edited character isnt selected or open in the game menu
10. Continue with Moxxi 
11. Overwrite .sav until complete
12. Look for desired perk combo or stat
13. Open cheat table and grab the string you want to continue building
14. Add new string to  Moxxi 
repeat until you complete your build
